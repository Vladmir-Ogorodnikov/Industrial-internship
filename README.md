# Практикум: три кейса по анализу данных

Учебная производственная практика. Три задания: поиск аномалий в журнале заявок, восстановление
бизнес-процесса по журналу событий и генерация продуктовых гипотез по дампу БД подписочного сервиса.
По каждому кейсу — отчёт, результаты в требуемом формате и код, которым эти результаты считаются.

| Кейс | Задача | Что сдаётся |
|---|---|---|
| [Кейс 1](https://github.com/Vladmir-Ogorodnikov/Case-1-) | найти нетипичное поведение заявок на закупку | [`anomalies.csv`](anomalies.csv) — 88 строк по 80 заявкам из 1 000, [`report.md`](report.md), [`analysis.py`](analysis.py) |
| [Кейс 2](https://github.com/Vladmir-Ogorodnikov/Case-2) | восстановить процесс по журналу без схемы | `process_map.png`, `variants.csv`, `student_transitions.csv`, `report.md`, `analyze.py` |
| [Кейс 3](https://github.com/Vladmir-Ogorodnikov/Case-3) | продуктовые гипотезы по данным VPN-сервиса | отчёт с шестью гипотезами, `out/*.json`, код на DuckDB |

В каждом репозитории свой `README.md`: что за данные, что получилось, как пересчитать. Также `report.md` - отчет по каждому кейсу 

## Как запустить

Нужен Python 3.10+ и виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
```

Зависимости по кейсам разные, общий `requirements.txt` не нужен:

```bash
pip install pandas numpy                  # Кейс 1
pip install pandas matplotlib             # Кейс 2 (+ pm4py для бонусной части)
pip install duckdb pandas pyarrow         # Кейс 3
```

```bash
python3 analysis.py students.csv anomalies.csv                    # Кейс 1
python analyze.py && python make_diagram.py && python bonus_pm4py.py   # Кейс 2
python case3_analysis.py && python h1_sensitivity.py && python analyze_logs.py   # Кейс 3
```


## Данные

- Выгрузки для Кейсов 1 и 2 в репозиториях не лежат: `students.csv` (12 162 события, 1 000 заявок,

  Колонки, ожидания по качеству данных и легенда маршрута для Кейса 1 — в разделе ниже.
- `Кейс 3/data/` — 43 таблицы, около 10 ГБ, плюс `logs.zip` на 5 ГБ. В репозиторий не входят,

## Коротко о результатах

**Кейс 1.** Обычное поведение описал по когортам «тип заявки × этап» и по рабочим часам, а не по
календарным. Нашёл 88 отклонений в 80 заявках (8 %): 48 нарушений регламента (пропуск согласования
руководителем, исполнение до утверждения бюджета, повторная проверка без возврата, чрезмерные циклы
доработки, этап закрыт не той ролью, в том числе самосогласование), 32 статистических отклонения
(аномально долгая проверка, формально быстрые закрытия, зависшее задание) и 8 наблюдений с
внеплановой проверкой auditor, которые требуют ручного обоснования. Правила, которые дали ложные
срабатывания, задокументированы с числами.

**Кейс 2.** Восстановил 10 активностей, один цикл доработки и три финальных состояния
(выполнено 911, отклонено 63, отменено 26). Основной маршрут — 56,7 % заявок, всего 8 вариантов и
12 переходов. Возврат «доработка → первичная проверка» — 174 перехода в 156 заявках (15,6 %), не
более двух итераций. Ветка «дополнительное согласование» наблюдается ровно у дошедших до проверки
бюджета заявок с суммой ≥ 150 000 (209 из 209, при меньшей сумме — 0 из 702); условие описано как
гипотеза, потому что сумма в модели процесса не задана. В бонусной части сравнил ручную модель с
Inductive Miner и Heuristic Miner из pm4py.

**Кейс 3.** Шесть гипотез с числами: повторные триалы на мультиаккаунтах (2,3 % всех триалов —
нижняя оценка, верхняя 38,2 %), лимиты бесплатного тарифа (4,05 подключения в день против 2,52,
47,9 % бесплатных дней — одно подключение; байтов в выгрузке нет, поэтому проверка только
прокси-метриками), время до покупки (триал даёт конверсию 40,6 % против 0,26 %, но 77 % оплат
приходят позже 30 дней), причины неудачных платежей (в основном брошенная корзина: медиана до
`failed` — 62 минуты, доля неудач упала с 39,8 % в марте до 15,6 % в июне 2026), реферальный канал
(конверсия 17,6 % против 0,80 % у органики на выборке 581 человек) и логи клиентов (926 архивов,
70,7 млн строк, 92,4 % ошибок — DNS-over-HTTPS, 91,5 % всех ошибок приходятся на 23 дня сентября 2026).
